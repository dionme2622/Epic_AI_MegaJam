# 기사 리깅 · 검 · 전투 대기 애니메이션

제공받은 무기 없는 기사 모델을 바탕으로 Blender에서 직접 뼈대, 스킨 웨이트, 검 메시와 키프레임을 제작했습니다. 트리포의 리깅이나 애니메이션 기능은 사용하지 않았습니다.

## 파일

| 파일 | 내용 |
|---|---|
| Knight_Sword_Combat_Idle.fbx | 캐릭터 + 뼈대 + 손에 든 검 + 전투 대기 애니메이션. 바로 확인할 기본 파일입니다. |
| Knight_Rigged_TPose.fbx | 검을 제외한 캐릭터의 T 자세와 같은 뼈대. 장갑은 검을 쥘 수 있는 주먹 형태입니다. |
| Knight_Sword.fbx | 별도 사용 가능한 검 메시. 은빛 칼날, 금색 가드, 갈색 손잡이, 자주색 장식. |
| Knight_Combat.blend | 수정 가능한 원본. 텍스처와 뼈대, 동작, 조명, 카메라를 포함합니다. |
| Knight_Combat_Idle.mp4 / .gif | 실제 3D 모델을 렌더한 4초 반복 미리보기. |
| Textures/ | 원본 캐릭터의 색상·노멀·거칠기·메탈릭 텍스처. FBX와 함께 보관하세요. |
| validation.json | 스킨 웨이트, 발 고정, 시작/종료 자세 및 FBX 재가져오기 검사 결과. |

## 동작과 뼈대

- 30fps, 1~121 프레임. 4초 주기의 제자리 호흡·작은 체중 이동. 121 프레임은 1 프레임과 같은 끝 키입니다.
- 21개 뼈: root, pelvis, 척추 2개, 목, 머리, 양쪽 쇄골·상완·전완·손·허벅지·종아리·발, weapon_r.
- 칼은 weapon_r에 100% 고정된 별도 메시로, 손 움직임을 따르며 칼날 자체는 휘지 않습니다.
- 오른손은 칼 손잡이를 쥔 형태, 왼손은 경계 자세의 주먹으로 직접 제작했습니다.
- 발목은 제자리에 유지되며 골반 높이 변화에 맞춰 다리 회전이 키프레임에 구워져 있습니다.
- 몸 애니메이션용 리그입니다. 얼굴 표정, 개별 손가락 조작, 망토 물리용 컨트롤은 포함하지 않습니다.

## 언리얼에서 열기

1. ZIP을 먼저 풉니다. Textures 폴더와 FBX의 상대 위치를 유지합니다.
2. Knight_Sword_Combat_Idle.fbx를 콘텐츠 브라우저로 가져옵니다.
3. Skeletal Mesh와 Import Animations를 켭니다. 최초 가져오기에서는 Skeleton을 비워 새 스켈레톤을 만듭니다.
4. 생성된 Animation Sequence를 열고 반복 재생으로 확인합니다. 엔진에서 전투 대기에 연결할 때도 Looping을 켭니다.
5. 이 FBX에는 이미 검이 들어 있습니다. 추가로 검을 붙이지 않아도 됩니다.

검을 장착·해제하는 시스템을 만들려면 Knight_Rigged_TPose.fbx와 별도 Knight_Sword.fbx를 사용하면 됩니다. 검은 Static Mesh로 가져와 weapon_r 또는 hand_r에 만든 소켓에 연결하고 소켓 위치/회전을 맞추세요. 검의 원점은 손잡이 중앙, 길이 방향은 Blender 기준 +Z, 장식이 있는 앞면은 -Y입니다. 단위는 미터이며 캐릭터 높이는 약 1.65m입니다.

FBX 재가져오기까지 확인했습니다. 언리얼 프로젝트 내부에서의 머티리얼 연결과 플레이 테스트는 별도로 진행해야 합니다.
