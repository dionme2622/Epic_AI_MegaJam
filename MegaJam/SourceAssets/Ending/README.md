# 엔딩 시퀀스

수레(2번)를 선택하면 `LS_BossEnding_Cart`가 이어집니다. 기존 바닥과 용사는 원래 높이를 유지합니다. 오른쪽 드래곤 바로 아래에만 `/ㅡ` 모양의 별도 석재 경사대가 나타나며, 수레와 드래곤이 높은 평지에서 왼쪽 경사를 빠르게 내려와 기존 평평한 바닥을 지나 화면 밖으로 나갑니다. 옆 차선·기둥·하부 도로는 없습니다. 경사대는 수레 선택 시 공개 장면부터 표시되며, 첫 대사 장면이나 다른 하체 선택에는 표시되지 않습니다.

수레 분기는 24fps, 144프레임(6초)입니다. 0.75초부터 굴러가며 경사 진입 후 이전보다 약 1.7배 강하게 가속합니다. 드래곤 공개 장면은 3초이며, 확대 구도에서 바로 수레 장면으로 이어집니다. 카메라는 확대 거리를 유지하며 하강을 따라가고 용사에 도달하면 그 구도에 머무릅니다. 경사대는 기존 바닥 위 x=550–1640, y=3.5에 있고, x=1000부터 높이 360cm(경사 약 39도)의 평지입니다. 바퀴의 접지 높이로 수레의 기울기를 계산하며, 바퀴는 이동 거리에 맞춰 회전합니다. “잠깐. 이거 브레이크는 어디—” / “Wait. Where are the brakes on this—” 뒤에 “으아아!!!” / “Aaaah!!!”를 한·영 자막으로 표시합니다. 제공된 Inworld Hades 보이스를 브레이크 대사 0.75초, 비명 3.292초에 재생합니다. 기존 자막은 유지하며 새 자막을 추가하지 않습니다. 자막은 0.75–3.3초와 3.3–5.75초이며, 3.42–4.08초에 용사가 제자리에서 180도 뒤돌아보며 지나가는 드래곤을 바라봅니다.

`build_cart_scene.py`로 수레 분기를 다시 생성합니다. `stage_baseline.json`은 잘못 기울였던 기존 바닥과 용사의 원래 변환이며, 재생성 시 이를 복구합니다. 기존 바닥에는 시퀀서 변환 트랙을 만들지 않습니다. `verify_cart_scene.py`를 PIE 시작 전에 실행하면 첫 장면부터 기존 바닥의 위치·회전 유지, 선택별 경사대 표시, 수레·드래곤 연결과 가속을 검사합니다. 인자는 `1 preview`로 출발 및 경사 구간에서 일시 정지하거나, `0`/`2`로 다른 분기를 확인합니다.
용사 다리(3번)를 선택하면 공개 장면 다음에 `LS_BossEnding_HeroLegs`가 자동 재생됩니다. 기존 작은 기사 하체를 장착한 드래곤이 0.5–3초 동안 일반 걷기 루프를 1.2배속으로 재생하는 빠른 걸음으로 용사 앞으로 다가와 멈춥니다. 3.5–6.5초에 용사의 “왜 내 다리가 저기 있는거야?” / “Why are my legs over there?”를 한·영 자막으로 표시하고, 7초에 반응 구도를 유지한 채 종료합니다. 정지 구간은 걷기 애니메이션의 시간을 0으로 고정하므로 짧은 루프가 반복되거나 발이 떨리지 않습니다. 제공된 Inworld Brick 보이스를 대사 시작인 3.5초에 연결했습니다.

`build_hero_legs_scene.py`로 이 분기만 다시 생성합니다. `Animation/A_HeroLegs_Scurry`는 기존 기사 하체 리그의 전용 1초 걷기 루프이며, `Ending_HeroLegs_Rig`가 작은 다리와 드래곤 상체를 함께 이동시킵니다. `verify_hero_legs_scene.py`를 PIE 전에 실행하면 3번 선택과 이동·발놀림·상하체 연결·수레 비표시를 검증합니다. `preview` 인자로 걸음과 자막 장면에서 정지해 확인할 수 있습니다.
원래 드래곤 하체(1번)를 선택하면 기존 공개·복귀 장면 다음에 `LS_BossEnding_OriginalLegs`가 자동 재생됩니다. 드래곤이 약 4.5초 동안 무릎을 굳힌 채 엇박자로 발을 옮겨 용사 쪽으로 다가오고 멈춥니다. 이어 용사의 “...너 원래 그렇게 걸었어?” / “...Have you always walked like that?”, 드래곤의 “하... 애니메이션은 또 왜 이래.” / “Sigh... What's wrong with the animation now?”를 한·영 자막으로 표시합니다. 이 후속 장면에는 Inworld Brick(용사), Hades(드래곤) 영어 보이스가 연결되어 있습니다.

새 장면은 24fps, 372프레임(15.5초)이며 걸음은 36–144프레임, 용사 음성은 156프레임(6.5초), 드래곤 음성은 243프레임(10.125초)에 시작하며 자막도 음성 길이에 맞춰 표시입니다. 원래 드래곤 리그에 만든 `Animation/A_Dragon_AwkwardWalk`를 사용합니다. 마지막에는 접근한 드래곤과 넓은 카메라 구도를 유지하고 `OnReadyForContinuation(0)`을 호출합니다. 이 장면은 원래 드래곤 하체에서만 재생됩니다. `build_original_legs_scene.py`로 이 장면만 다시 생성할 수 있습니다.

Unreal Editor에서 `/Game/DirectorCut/Ending/L_BossEnding`을 열고 **Play**를 누릅니다.

- **0–약 10.46초**: 프롤로그와 같은 위치·카메라에서 용사와 드래곤의 요청된 한국어 대사를 위에, 영어 번역을 아래에 표시하며 드래곤의 기존 Idle 모션을 재생합니다. 용사에는 Inworld Brick, 드래곤에는 Inworld Hades 영어 음성을 재생합니다.
- **선택 대기**: 실제 장착 모습의 사진과 `Dragon Legs`, `Cart`, `Hero's Legs`를 표시합니다. 카드 클릭, **1 / 2 / 3**, 또는 **← / → + Enter**로 선택합니다. 시간 제한은 없습니다.
- **선택 후 0–1.5초**: 드래곤 전체를 볼 수 있는 구도로 카메라가 이동합니다.
- **1.5–3초**: 선택한 하체를 장착한 드래곤을 보여줍니다.
- **3초**: 확대 구도에서 바로 선택한 후속 장면으로 이어집니다.
- **3초 이후**: 수레는 확대 구도에서 하강을 추적하다 용사를 비추고, 원래 드래곤 하체는 해당 후속 장면으로 이어집니다. 용사 다리 선택은 종종걸음 등장과 용사 대사 장면으로 이어집니다.

편집할 시퀀스는 `LS_BossEnding_Dialogue`, `LS_BossEnding_Reveal`입니다. 대사 시간과 문구, 모델 및 사진 참조는 맵의 `Ending_Controller` 세부 정보에 있습니다. 추후 음성은 대사 시퀀스에 Audio 트랙으로 추가할 수 있습니다.

후속 장면은 `DirectorCutEnding`을 상속한 Blueprint의 `OnReadyForContinuation(OptionIndex)` 이벤트에서 연결할 수 있습니다. 선택 값은 0=드래곤, 1=수레, 2=용사 다리이며 `GetSelectedLowerBody()`로 조회할 수 있습니다. 현재는 시네마틱 종료 구도를 유지하기 위해 이동 입력을 막습니다.

사용 모델은 기존 `SK_Dragon_Origin`, `SK_Dragon_Upper`, `SM_Dragon_Ride_Cart` 및 바퀴 4개, `SK_Knight_LowerBody`입니다. 사진 원본은 이 폴더의 `Images/`에 보관했습니다.

`build_ending.py`는 엔딩 소유 액터·시퀀스를 다시 만듭니다. 에디터에서 **Tools → Execute Python Script**로 실행합니다. 엔딩 맵이 없으면 기존 프롤로그를 복제하며, 이후에는 엔딩 맵만 수정합니다. 실행 전 수동으로 수정한 엔딩을 별도 저장하세요.


음성은 Voice/에 원본 MP3와 48 kHz 모노 WAV로 보관합니다. install_voices.py로 기존 맵의 보이스만 다시 적용할 수 있습니다. 용사 시작 14프레임(0.583초), 드래곤 시작 130프레임(5.417초)이며, 두 언어 자막도 음성 길이에 맞춰 표시합니다.

엔딩 첫 대사 시퀀스에서 0–0.5초 동안 한 번만 페이드 인합니다. 용사의 첫 음성은 14프레임(0.583초)에 시작하므로 페이드 인이 먼저 끝납니다. 세 하체 후속 시퀀스(원래 드래곤 다리·수레·용사 다리)는 시작 페이드 없이 바로 이어지고 마지막 0.75초에만 검은색으로 페이드 아웃합니다. 마지막 검은 화면을 유지하며 보이스는 음량 페이드 없이 끝까지 재생합니다. `configure_branch_fades.py`로 세 분기의 페이드를 다시 적용합니다.
