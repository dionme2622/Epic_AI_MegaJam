# 감독판 엔딩 카드

각 다리 분기의 후속 시퀀스가 끝난 뒤 나타납니다. 기존 0.75초 페이드아웃과 대사를 유지합니다.

- 시퀀스 종료 후 0–0.65초: 검정 화면.
- 0.65초부터: 실제 선택 모델 사진을 담은 인화지가 중앙에 등장합니다. 사진은 -7도에서 -4도로 기울기가 정리되고 위에서 36px 내려앉습니다.
- 1.65–2.3초: 위쪽에 `나의 감독판 / MY DIRECTOR'S CUT` 제목이 나타납니다.
- 인화지 하단 엔딩명: `원래의 나로 / BACK TO MYSELF`.
- 수레 엔딩명: `멈출 수 없는 감독판 / NO BRAKES, JUST TAKES`.
- 용사 다리 엔딩명: `빌려온 당당함 / BORROWED CONFIDENCE`.
- 제목이 완전히 나타난 뒤 5초간 최종 카드를 유지합니다.
- 카드 등장 시작 기준 7.3–7.9초에 사진과 제목이 함께 사라지고, 8.1초에 로비(`/Game/DirectorCut/Lobby/L_DirectorCutLobby`)로 자동 복귀합니다.

사진은 Ending_Controller의 OptionImages[선택 값]을 사용합니다. 0=원래 다리, 1=수레, 2=용사 다리로 실제 선택 모델의 기존 게임 렌더 이미지입니다. 교체하려면 이 텍스처 참조를 변경하면 됩니다. 1920×1080 기준 레이아웃이 뷰포트 크기에 맞춰 비율을 유지하며 축소/확대됩니다.

구현: DirectorCutEnding.cpp의 CreateOverlay, FinishBranchScene, Tick.
